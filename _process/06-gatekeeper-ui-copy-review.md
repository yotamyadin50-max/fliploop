### What needs work
1. **Singular counts render as plurals on the Print screen, for the most common case.** A project of 8 or fewer frames prints on 1 sheet, so a first 2-frame animation shows `print.summary` as "2 כרטיסים · 1 גיליונות", and the toasts read "ה-PDF ירד: 1 גיליונות" and "ירדו 1 קובצי PNG". The file defines `.one` / `.other` keys but did not apply them here. Fix, add the singular keys:
   - `print.summary` → split the two counts: `print.summary.cards.one` "כרטיס אחד", `print.summary.cards.other` "{cards} כרטיסים", `print.summary.sheets.one` "גיליון אחד", `print.summary.sheets.other` "{sheets} גיליונות", joined with " · ".
   - `print.done.pdf.one` "ה-PDF ירד: גיליון אחד" (keep `.other` as is).
   - `print.done.png.one` "ירד קובץ PNG אחד" (keep `.other` as is).
   - `print.preview.sheet.aria`: the last sheet can hold 1 card; use the same `cards.one` / `cards.other` pair.
2. **`frameMenu.hold.value.aria` is wrong at the default value.** Hold starts at ×1, so every screen-reader user opening the frame menu hears "החזקה ×1: הפריים נשאר 1 פעמים יותר זמן", which is ungrammatical and false (×1 is normal length). Fix: `frameMenu.hold.value.aria.one` "החזקה ×1: אורך רגיל" and `frameMenu.hold.value.aria.other` "החזקה ×{hold}: הפריים נשאר על המסך פי {hold}".

Fix: one string of 24 chars that keeps both jobs, `coach.2` "הוסיפו פריים וציירו הלאה", and delete `coach.2.short` along with its Developer note.
