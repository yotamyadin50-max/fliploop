Owner: 02 (warning table), with one styling line in 03.** The packet (section 2, "More") asks for "a clear message if device storage/memory approaches its limit." W1, W2, W2b and W4 cover storage quota and frame count; W3 covers a failed write. Nothing tells the user when memory gets tight: 02 line 65 silently drops the oldest undo steps of non-current frames once the 64 MB (or 32 MB) budget is hit, which is also the one place the plan departs from the user's "50 undo steps PER FRAME" (03b "Accepted deviation"), and the user is never told. -> Add a row to the 02 warning table: **W5 Memory tight.** Trigger: the undo budget evicts steps for the first time in a session, or `navigator.deviceMemory` is 2 or less and the project reaches 60 frames. Where: a one-time toast in the Editor per session (not blocking). Message direction: "הזיכרון במכשיר מתמלא. בפריימים אחרים נשמרים פחות צעדי ביטול; בפריים הנוכחי נשמרים 50." 2. **Ambiguous canvas-tap rule could start playback while drawing. Owner: 02 line 95.** The state table (line 90) says a canvas tap *stops* playback; the Stop rule says "Space, Play, or a canvas tap toggles," which read literally makes a single tap to draw a dot start Play in the Ready state. -> Replace with: "Space and Play toggle playback. A canvas tap only stops it; in Ready it draws."
3. **Challenge week label and days-left are undefined, and a wrong device clock breaks the theme lookup. Owner: 02 line 233 to 234.** The sample "שבוע 39 · נשארו 3 ימים" does not follow from the formula: on 2026-09-28, weekIndex = floor(267/7) = 38, and 5 or 6 days remain in the week, not 3. Nothing says whether the label is weekIndex or weekIndex + 1, how days left are counted, and `weekIndex mod 52` in JavaScript returns a negative index (undefined theme) on any device clock set before 2026-01-04. -> State: "Label = weekIndex + 1. Days left = 7 minus days since this week's Sunday (today counts as a day left; Saturday shows 'יום אחרון'). Theme index = ((weekIndex mod 52) + 52) mod 52." Fix the sample to match (for example "שבוע 39 · נשארו 6 ימים").
